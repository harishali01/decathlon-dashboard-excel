Decathlon Sales & Customer Analytics Dashboard (Excel)

Smarter insights. Stronger connections. Better performance.

An interactive Excel dashboard built to analyze Decathlon's sales, orders, and customer data (2024–2026) using Pivot Tables, Pivot Charts, Slicers, and formulas — no external BI tool used, everything done natively in Exce

Overview

This dashboard gives a 360° view of sales performance and customer behavior for a sports retail brand (Decathlon), covering:

Overall sales, orders, customers, and average order value (AOV)
Sales trends over time (month-wise)
Top-performing sports categories
Sales breakdown by product category and gender
Customer retention rate trend
Year-wise filtering (2024 / 2025 / 2026) using Slicers

Tools & Features Used
Microsoft Excel
Pivot Tables & Pivot Charts
Slicers (Year-wise filtering: 2024, 2025, 2026)
Sparklines (for KPI trend mini-charts)
Formulas: SUMIFS, COUNTIFS, DISTINCT COUNT, YoY % calculations
Custom KPI cards with icons for a clean, professional dashboard layout
